# Decisions

1. Modular monolith before services: lower operational cost and simpler transactions.
2. Structured block JSON before free canvas: responsive guarantees and safe validation.
3. Supabase SSR with publishable keys: server-verifiable identity and tenant RLS.
4. Signed credit ledger: immutable accounting events; reservations precede provider jobs.
5. Honest fallbacks: deterministic AI mock and mock billing expose their mode and cannot produce production success.
